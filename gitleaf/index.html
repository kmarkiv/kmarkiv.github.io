Write wherever you are

Prepare for offline LaTeX writing.

Your files, editor, PDF viewer and local Git history stay available without a connection.

  1. Set up while online.

    Download GitLeaf, install Git, then install Tectonic or a full LaTeX distribution with latexmk.

  2. Compile your paper once.

    Include its bibliography and figures. Tectonic downloads and caches needed packages; full LaTeX uses packages installed on your computer.

  3. Test without a connection.

    Try compiling that paper without internet. New packages may still need a download; remote Git operations, online templates and updates need a connection.

A few useful details

Before you begin.

Can I use GitLeaf instead of Overleaf?

GitLeaf offers a similar source-and-PDF workflow on your computer. Import an Overleaf source ZIP, or use Overleaf’s Git bridge if your account supports it. Collaboration uses Git; live simultaneous editing is not included.

Is GitLeaf free?

Yes. GitLeaf is free and open source under the MIT license. Local writing needs no account or subscription. Optional third-party services such as Overleaf’s Git bridge have their own access requirements.

Do I need to install LaTeX?

You need Git, but you can start without a LaTeX installation. On your first Compile, GitLeaf offers to install Tectonic if no compiler is found. You can also install MacTeX or TeX Live with latexmk. See compiler options.

Can I edit and compile LaTeX offline?

The editor and your local files work offline. Tectonic needs internet to fetch packages it has not cached. A full LaTeX installation can compile using its installed packages offline. Downloads and remote Git operations need internet. Follow the offline setup checklist.

Where is the full documentation?

The setup and reference guide comes from the GitHub README. It includes compiler choices, troubleshooting, configuration and source builds.
